Step 3: SQL Analysis - Answering Business Questions
Query 1: Business Problem 1 - The Smoking Penalty
Why: To calculate and compare the average medical costs for smokers and non-smokers.

What: This query groups everyone by their smoking status and calculates the average charge for each group.

How:

SQL

SELECT
    smoker,
    COUNT(*) AS number_of_customers,
    AVG(charges) AS average_charge
FROM
    costs
GROUP BY
    smoker;
Line-by-Line Explanation:

SELECT smoker, ...: We want to see the smoker status ('yes' or 'no').

COUNT(*) AS number_of_customers: We also want to count the number of people in each group and name this column number_of_customers.

AVG(charges) AS average_charge: And we want the average of the charges for each group, naming it average_charge.

FROM costs: Get the data from our costs table.

GROUP BY smoker;: This is the key command that separates people into 'yes' and 'no' smoker groups before doing the calculations.

Result: You will immediately see that smokers cost the company thousands of dollars more on average. A huge finding!

Query 2: Business Problem 2 - Regional Price Puzzles
Why: To see if average medical costs differ by geographic region.

What: This query groups customers by region and calculates the average charge, sorting them from most to least expensive.

How:

SQL

SELECT
    region,
    AVG(charges) AS average_charge
FROM
    costs
GROUP BY
    region
ORDER BY
    average_charge DESC;
Line-by-Line Explanation:

SELECT region, AVG(charges) ...: Select the region name and calculate the average charge.

FROM costs: From our costs table.

GROUP BY region: Group the calculations by each unique region.

ORDER BY average_charge DESC;: Sort the final results in descending (DESC) order to put the most expensive region at the top.

Code Block 5: Feature Engineering - Creating New Insights
Why: Let's create a new, helpful bmi_category column. This will make it much easier to filter and analyze in our dashboard later.

# Define a function to categorize a person's BMI
def categorize_bmi(bmi):
    if bmi < 18.5:
        return 'Underweight'
    elif 18.5 <= bmi < 25:
        return 'Normal'
    elif 25 <= bmi < 30:
        return 'Overweight'
    else:
        return 'Obese'

# Create a new column 'bmi_category' by applying our function to the 'bmi' column
df['bmi_category'] = df['bmi'].apply(categorize_bmi)

# Check the first few rows to see our new column in action
df.head()
